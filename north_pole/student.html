Import music and assign MIDI tracks

Use matching MIDI + MP3 files. MIDI provides exact notes and tempo; audio alone does not identify instruments or beats. Supported meters: 3/4, 4/4, 6/8, with meter changes on measure boundaries.

Each note creates the selected effect; velocity sets brightness. Notes and MP3 are embedded in the next project download. Offset changes new generated cues only.
