# The one-more-house pass

This pass responds to a simulated ten-year-old review, not feedback from an actual child.

- Brief first-move cards put the longer rules in the journal. Fresh zero-elapsed runs wait for an object action before pressure advances. Existing saves retain their time and progress.
- Nearby routine interactions use the E button directly; multi-action plants and receipt memories have a small world-action tray. Contracts, accusations and endings remain deliberate modal decisions. The inspection UI remains available to compatibility/browser flows.
- Bell/clock/plant/cabinet responses pulse briefly, unless reduced motion is active. Empty cabinets and completed plants remain visible, without repeat rewards.
- Plant appetite symbols and impostor clues have geometry. Text remains available for accessibility. The Collector appears at the certified hiding anchor when alarm rises; footsteps quicken. This is a staged presence, not a navigation/chase AI.
- Sixteen bounded visual ending performances accompany choices. An unobtrusive ending card leaves the world visible. They are stylized miniature magical performances, not cinematics that remodel the house. The player can leave immediately.
- Four relics have a visual cabinet with effects, discovered state and next-house equipment. It uses existing saved reward identities.
- Scares require a central camera view and unobstructed ray before buildup and impact. A blocked buildup cancels and can retry after cooldown. Rendered checks compare pixels with/without the performer; object existence alone is insufficient.

Validation: core/scene suites; added direct-action and reward invariants, 16 ending/resource checks, reduced motion and occlusion checks. The new WebGL suite tests safe practice, a clock sequence through keyboard actions, plant error/recovery, Collector, actual ending, sixteen staged visual captures, relic equipment and mobile layout. Existing full-haunting tests remain separate from staged visual evidence.

Still requires a child playtest: first-minute comprehension, meaningful ending preference, whether the Collector feels threatening, and whether the next house earns another turn. Hardware Chromebook frame rate is not established by software WebGL.
