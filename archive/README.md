# Retired standalone engine

`black-hollow-v8.html` is the former root game, retained for historical source review. It is not included in the GitHub Pages artifact. Root `index.html` now directs players to the current prepared-CASA Game.

Its source-level checks remain available through `npm run test:legacy`. The historical Python browser harness reads this archived source and injects it at its local server's root, where the retained root assets resolve. Those checks do not establish current Game behavior.
